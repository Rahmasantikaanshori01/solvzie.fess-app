# solvzie.fess-app

# Anonymous Messaging NGL

Aplikasi anonymous messaging yang memungkinkan pengguna membuat dan membagikan link NGL untuk menerima pesan anonim. Pengguna dapat mengelola beberapa NGL, menyesuaikan desain halaman NGL, menerima pesan, serta membagikan pesan yang diterima ke Instagram Story.

Aplikasi ini terdiri dari Admin Web, User Mobile App, dan Public NGL Web yang saling terintegrasi.

## 📌 Tentang Proyek

Proyek ini dikembangkan sebagai bagian dari kegiatan Praktik Kerja Lapangan (PKL) dengan tujuan membangun platform anonymous messaging yang memungkinkan pengguna menerima pesan anonim melalui link yang dapat dibagikan kepada orang lain.

## ✨ Fitur Utama

### Admin Web
- Dashboard statistik aplikasi.
- Pengelolaan akun User.
- Pengelolaan NGL.
- Pemantauan pesan anonim.
- Activity Log.
- Pengaturan platform.

### User Mobile App
- Registrasi dan Login.
- Dashboard pengguna.
- Membuat NGL Songfess dan Menfess.
- Kustomisasi desain NGL menggunakan foto template atau gradasi warna.
- Membuat dan membagikan link NGL.
- Mengaktifkan dan menonaktifkan link NGL.
- Inbox pesan anonim.
- Membuat desain Instagram Story dari pesan yang diterima.
- Archive pesan.
- Pengaturan profil dan akun.

### Public NGL Web
- Halaman NGL yang dapat diakses melalui link.
- Tampilan background berdasarkan desain User.
- Pengiriman pesan anonim tanpa login.
- Pratinjau pesan sebelum dikirim.
- Pengiriman pesan kepada pemilik NGL.

## 📱 Arsitektur Aplikasi

Aplikasi terdiri dari tiga bagian utama:

- **Admin Web** — digunakan Admin untuk mengelola dan memantau keseluruhan platform.
- **User Mobile App** — digunakan User untuk membuat, mengelola NGL, serta menerima dan membagikan pesan.
- **Public NGL Web** — digunakan pengunjung untuk mengirim pesan anonim melalui link NGL.

Ketiga bagian aplikasi terhubung melalui backend dan database yang sama.

## 🔄 Alur Aplikasi

1. User membuat NGL melalui Mobile App.
2. User menentukan desain NGL dan membuat link.
3. User membagikan link NGL.
4. Pengunjung membuka link melalui browser.
5. Pengunjung menuliskan pesan anonim dan melihat pratinjau.
6. Pengunjung mengirim pesan.
7. Pesan diterima oleh User melalui Inbox.
8. User dapat membuat desain Instagram Story dari pesan yang diterima.
9. Pesan yang telah dikonfirmasi dibagikan dapat dipindahkan ke Archive.

## 🎯 Tujuan Pengembangan

- Membangun platform pengiriman pesan anonim berbasis link.
- Memudahkan pengguna membuat dan mengelola NGL.
- Menyediakan kustomisasi desain NGL.
- Mengintegrasikan Web dan Mobile App.
- Memberikan pengalaman penggunaan yang sederhana dan mudah dipahami.
